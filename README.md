Лабораторная работа 2

Система управления заказами доставкой и акциями на C++17

Для сборки нужны CMake и компилятор C++

Запуск меню

```sh
./start
```

Запуск тестов

```sh
./start test
```

Пять сценариев из задания

```sh
./start demo
```

В меню можно создавать заказы добавлять и удалять товары применять акции
Также можно назначать доставку менять статус заказа и смотреть статистику
Сначала нужно ввести лимит активных заказов на одного клиента
Регион Vladivostok не обслуживают курьер и почта это проверяет прокси
После выхода данные не сохраняются

include содержит заголовки классов
src содержит реализацию и сценарии
tests содержит проверки по заданию
docs содержит отчет и диаграмму
